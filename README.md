## 🌐 Demo
https://danielsalinas123.github.io/agencia-web-frontend/

## 🧩 Descripción

Este proyecto consiste en el diseño y maquetación frontend de una **landing page corporativa** para una agencia digital ficticia.

El objetivo fue construir una interfaz moderna, clara y profesional, aplicando buenas prácticas de **HTML, CSS y JavaScript vanilla**, sin utilizar frameworks ni librerías externas.

El proyecto está orientado exclusivamente al **frontend**, sin lógica de backend ni consumo de APIs.

---

## 🛠️ Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript (Vanilla)

**Sin frameworks ni librerías externas**

---

## 📱 Características principales

- ✅ Diseño completamente **responsive** (mobile, tablet y desktop)
- ✅ Menú de navegación interactivo con JavaScript
- ✅ Implementación de **modo oscuro**
- ✅ Mejoras de **accesibilidad**
- ✅ Estructura de código clara y organizada
- ✅ Buenas prácticas de maquetación frontend

## ♿ Accesibilidad

Se aplicaron mejoras para facilitar la escalabilidad y legibilidad del contenido:

- Uso de unidades relativas (`rem`)
- Mejor manejo de contraste
- Compatibilidad con modo oscuro
- Ajustes visuales para distintos contextos de uso

---

## 🌙 Modo oscuro

Se implementó una variante visual alternativa enfocada en la comodidad en entornos con poca luz, manteniendo coherencia visual y contraste adecuado.

---

## 🧠 Funcionalidad con JavaScript

Se añadió lógica en JavaScript para:

- Interacción del menú de navegación en dispositivos móviles
- Mejorar la experiencia de usuario sin dependencias externas
